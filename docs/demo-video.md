# Hotbar 利用動画

準備する成果物:

| 用途 | 画角 | 長さ | 出力 |
|---|---|---|---|
| 販売ページ | 1920×1080 | 25秒 | hotbar-website.mp4 |
| Xなどの告知 | 1280×720 | 15秒 | hotbar-social.mp4 |
| ショート動画 | 1080×1920 | 30秒 | hotbar-vertical.mp4 |

実写の画面収録を使用する。無音・日本語字幕付き。縦版でも操作UIを切り取らず、余白に字幕を置く。

## 撮影手順

1. 個人情報のないデモ用ウィンドウを用意する。
2. HotbarはToggleモードにし、デモ以外のアプリをFiltersで除外する。元の設定を控える。
3. 30秒以上録画する。0〜5秒で⌥Tabを押して一覧を開き、5〜10秒で切り替え、10〜12秒で再度開いて左半分または右半分への配置を見せる。残りは最大化、並び順や色の設定を見せる。
4. 撮影後、元の設定を戻す。
5. 以下で3種類を生成し、実際の操作と字幕のタイミングが一致するか確認する。必要に応じてexport.pyの字幕タイミングを調整する。

```sh
python3 scripts/video/export.py /absolute/path/to/recording.mov
```

ffmpeg/ffprobeが必要。録画は macOS の Shift + Command + 5 から「選択部分を収録」で行える。30秒以上収録し、元の MOV ファイルを保存する。ユーザーが許可した screencapture コマンドも利用可能。
